# Changelog

## 1.0.0 — 2026-11-01

First public release of ICE for rEFInd 0.14.2.

- Native 1080p and 4K assets with black/ice-blue styling and subtle scanlines.
- Keyboard selection brightens icon strokes without a border or halo.
- Spanish prebuilt layout, English preset and configurable generator.
- Windows-only preset; optional static hardware labels and MOK tool.
- Real VM screenshots, interactive preview, documented installation and rollback.
- MIT project license and bundled OFL font licenses.

Test scope: two main entries and five tools at both resolutions in QEMU/OVMF. This is a visual theme, not a bootloader installer or a recovery image. Physical firmware support and OS boot paths depend on the target machine.
